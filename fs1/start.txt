# Start the Smart Knob

## Terminal 1 — PC Server
cd /workspaces/knob-controller/fs1
python3 server.py
# Listens on WS :8765. Drives bootstrap → config → launcher flow.
# Routes app commands (volume, brightness, zoom, scroll) to system.

## Terminal 2 — Test Bridge (browser sim)
cd /workspaces/knob-controller/fs1
python3 test-env/testKnob.py
# HTTP :8080 (sim UI) + WS :8766 (transparent pipe to server.py).
# Zero logic — pure forwarder.

## Browser
Open http://localhost:8080

## Expected flow in the WS log
 1. WS connects → status dot green
 2. Machine dropdown populates (Development Sim, Office PC, Home Mac)
 3. Server sends bootstrap.py (with _AVAILABLE_MACHINES injected) → sim runs it → bootstrap_response back
 4. Server matches GUID to machine config → sends config → sim acks
 5. Server sends launcher.py → sim builds app UI, prints launcher_ready

## Keyboard shortcuts (in browser sim)
  ← / ↓    Rotate encoder CCW
  → / ↑    Rotate encoder CW
  Space    Press encoder button
  Ctrl+Enter   Run code in editor

## Add a machine config
Create fs1/machines/<guid>.json. See existing files for the schema.
Restart server.py — it picks up new configs on next connection.
